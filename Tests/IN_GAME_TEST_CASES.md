# DMM 框架与 14 个插件游戏内测试用例

配套说明、原版功能追踪、已发现的源码差异、测试准备与记录模板见 [游戏内验收方案](IN_GAME_TEST_PLAN.md)。本文件所有用例及子项初始状态均为 **未执行**，没有预填实机通过结果。

## 执行约定

除特别说明外，前置条件为操作者已手动启动当前 RE 游戏、正常进入主页、仅启用目标插件、已安装适用资源。修改开关需点击“保存功能开关”，修改独立参数需保存；观察游戏实际结果及运行状态，再进入下一步。“关闭”均指停用目标插件并确认恢复，不是只关闭面板。测试结束恢复本条开始前的配置和测试资源。

“原版一致”指配套方案的独立原版会话实际结果；“原生恢复”指相同条件下游戏原来的行为。恢复应遵循该插件承诺的时机：明确支持即时恢复的不能靠重进场景冒充通过；在下一次真实调用才生效的功能要分别记录当前画面与下一次触发。

证据代码：**V** 为画面/录像；**L** 为对应时间段日志和运行状态；**F** 为配置/输出/资源文件读回；**N** 为脱敏请求平台、完成状态与余额证据；**M** 为实测帧时间、内存或操作耗时。诊断只能辅助实际游戏路径，不能用测试替身补结果。

一行包含多个明确输入时，各输入作为子项独立执行记录。依赖实验包、受控网络、非默认窗口环境或特殊账号的项目，未备齐条件记“阻塞”。安装恢复、权限故障与异常中断必须在可恢复环境执行，不能直接损坏用户当前资源；不实际付款，不伪造服务端响应，不对第三方服务发起攻击。
