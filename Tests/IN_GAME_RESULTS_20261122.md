## 缺陷与移植差异

### D-01 文本与字体 SetText 接入缺失

类别：实际运行兼容缺口；优先级 P1；状态：日志已确认，视觉影响范围待复现。

当前会话 03:37:06.601 字体与 03:37:08.338～339 文本日志均报告 Shared native code has incompatible IL2CPP signatures，涉及 TMP_Text.SetText(System.String) / SetText(System.String,System.Boolean)，共享地址 0x7FF8D31BCCE0。原 DMM Hook.cpp 2859/2865 行有这两个实际 ADD_HOOK。RE GenericText.Bind/FallbackFont.Bind 捕获 NotSupportedException 后继续。

这证明当前入口没有接入，不证明所有使用它的页面必然漏翻：内部切片等入口可能覆盖部分路径。需要找到真实使用这两个重载且能排除其他入口代偿的页面，分别验证文字和字体。不得删除 ABI 检查或强挂 Hook 来让测试通过。

### D-02 接入缺失未汇入运行诊断

类别：可观测性；优先级 P1；状态：日志和 UI 已观察，完整参数页待核对。

与 D-01 同一会话，点击面板“运行状态”只显示已启用六项，没有上述跳过入口。源码 GenericText 未实现 IPluginDiagnostics；FallbackFont 的该 catch 也只记录日志，没有加入 warnings；PluginComponents 汇总 Start 失败和 IPluginDiagnostics。当前有“部分入口缺失但状态像正常启用”的误判风险。

### D-03 原版 F11 全屏未见移植且实测无效

类别：移植缺项；优先级 P1；状态：RE 首次实测复现，原版实机对照尚未执行。

前提 window 已加载、resizable 缺省 true、输入工具权限已恢复且 Ctrl+U 可用。F11 后窗口保持 578×1055 带标题栏。原 DMM windowsPlatform.cpp 330～332 行对 F11 调 SwitchFullScreen；RE Window.Plugin 未实现该快捷键。需补测重复触发/不同方向和原版同版本行为后给完整用例结论。

### D-04 最大化进入普通最大化窗口而非原版全屏
